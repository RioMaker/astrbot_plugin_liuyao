# astrbot_plugin_liuyao

面向 QQ 群（OneBot v11 / aiocqhttp）的六爻起卦插件。支持两条等价命令入口、即时天机、手动铜币或卦名起卦、按术数分别保存的群开关，以及 AstrBot Agent Tool。

## 功能

- 双入口：`/六爻 ...` 与 `/起卦 六爻 ...` 功能完全相同；可直接在根指令后填写问卦内容。
- 即时起卦：用系统安全随机源模拟每爻三枚铜币，保持 6/7/8/9 的 1:3:3:1 概率。
- 手动起卦：
  - 接受六个 6/7/8/9；
  - 接受六组三枚铜币字符；
  - 接受 `乾`、`乾为天`、`天风姤`、`第1卦`、`䷀` 等卦名，按无动爻静卦处理。
- 离线古籍：内置文王卦序 64 卦、64 条卦辞和 384 条基础爻辞；乾、坤另保留用九/用六。
- 意图方向：综合、事业、感情、财富、学业、健康、家庭、出行。
- 分术数开关：保存结构为“群 → 术数 → 状态”；当前只有六爻，后续增加其他术数不会共用同一个开关。
- 权限：QQ 群主和 QQ 群管理员都可以设置本群术数开关。
- Agent 调用：提供 `cast_liuyao` 和 `lookup_zhouyi_text` 两个工具。

## 指令

两种写法完全等价：

```text
/六爻 <问卦内容>
/起卦 六爻 <问卦内容>
/六爻 [方向] <问卦内容>
/起卦 六爻 [方向] <问卦内容>

/六爻 即时 [方向] [问题]
/起卦 六爻 即时 [方向] [问题]

/六爻 手动 <六爻或卦名> [方向] [问题]
/起卦 六爻 手动 <六爻或卦名> [方向] [问题]

/六爻 开
/六爻 关
/六爻 状态
/起卦 六爻 开|关|状态

/六爻 help
/起卦 六爻 help
```

示例：

```text
/六爻 开
/六爻 今年是否适合换工作
/六爻 事业 今年是否适合换工作
/起卦 六爻 感情 这段关系该如何推进
/六爻 即时 事业 今年是否适合换工作
/六爻 手动 7 8 9 6 7 8 感情 这段关系该如何推进
/六爻 手动 正反反 正正反 正正正 反反反 正反反 正正反 财富
/六爻 手动 乾为天 事业 这个项目应该如何推进
/起卦 六爻 手动 天风姤 综合 目前局势该怎么看
```

根指令后的首个词若是受支持的方向（如 `事业`、`感情`），插件会将其识别为意图；否则整段文本按“综合”方向的问题处理。`即时`、`手动`、`开`、`关`、`状态`、`help` 等保留子命令继续有效。

六爻输入顺序固定为初爻到上爻，即自下而上。铜币记法约定为：

- 正 / 字 / 阳 / H = 3
- 反 / 花 / 阴 / T = 2
- 合计 6=老阴、7=少阳、8=少阴、9=老阳

直接输入卦名时没有手摇动爻信息，因此插件会用少阴/少阳构造静卦，并明确标记“手动指定卦名（静卦）”。

## 开关与升级兼容

新版本使用：

```json
{
  "群号": {
    "liuyao": true
  }
}
```

当前只有 `liuyao`，结构已为未来的梅花、奇门等其他术数预留独立状态。插件仍会读取 0.1.x 的旧 `group_switches = {群号: bool}` 数据，不需要手工迁移。

`/六爻 开关 开|关|状态` 旧写法仍保留兼容，但推荐使用 `/六爻 开|关|状态`。

## Agent 用法

用户可以直接说“为我起一卦问事业”。Agent 可调用：

- `cast_liuyao(mode, intent, question, manual_lines)`：即时起卦，或在 manual 模式传入六爻结果/卦名。
- `lookup_zhouyi_text(hexagram, line)`：按文王卦序查询卦辞或某一爻原文。

工具只在已启用六爻的 QQ 群内工作。普通指令不会自动调用模型；通过 Agent 使用时，由当前 Agent 对工具结果进行解释。

## 安装与配置

把本目录放入 AstrBot 的 `data/plugins/`，在 WebUI 重载插件。最低 AstrBot 版本为 4.9.2。

配置项：

- `default_enabled`：各术数在新群中的默认状态，建议保持 `false`。
- `allow_operator_api_lookup`：原始事件缺少 `sender.role` 时，读取 OneBot 群成员资料核验群主/群管理员。
- `max_question_length`：问题最大长度。
- `show_disclaimer`：普通指令是否显示传统文化参考提示。

## 数据与扩充

`data/zhouyi.json` 是运行时离线数据；`scripts/build_zhouyi_corpus.py` 只在开发阶段从维基文库公开 API 重建它。意图结构与候选签词在 `data/intents.json`。

来源、版本和后续古籍候选见 [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md)。
