# 基础笔记：从问事、取用到动变、应期与复盘

研读日期：2026-09-24。此文是现代整理，不是原典全文。例证链接到十类文档；每类的三例单独计数，本篇交叉引用不重复计数。书源与版本见 [来源](sources.md)。

## 1. 先定问题，再定方法

先保存原问、起卦人与代占关系、地点、时段、已知背景和真正要判断的结果。问“能否到任”“到任后安否”“何时获任”不同；问“下雨否”“雨是否妨碍行船”也不同。不要等答案出现再改原问或改用神。

本批纳甲主线以《增删卜易》分类篇为主。该书《用神章》以父母取长辈、文书、舟车、宅舍等，以官鬼取功名等，以妻财取财物等，兄弟、子孙依人与事分用；不是“官鬼永凶、子孙永吉”。具体差别见 [健康](topics/health.md)、[事业](topics/career.md)、[天气](topics/weather.md)。

《周易》卦爻辞可核对语义和所处阶段，但不是给纳甲生克自动加权的另一张万能吉凶表。《梅花易数》的体用互变和《火珠林》的财鬼射覆另标体系，见 [射覆](topics/shefu.md)。不得因为某书结论合意而临时换派压过不利证据。

## 2. 数据与名词先对齐

六爻由初至上编号；动爻的阴阳变化构成本卦到之卦。静卦也可研判，但没有用户提供的动爻就不能杜撰。直接输入卦名时，本插件按静卦处理，不声称还原古例筮法。

纳甲六亲以本卦卦宫五行为参照：“生我”父母、“我生”子孙、“克我”官鬼、“我克”妻财、“同我”兄弟。这里的“我”是定六亲的宫，不等于每条爻都是问卦人。世表示自身位置、应常表示相对一方，仍须按问事具体解释；不可把应在任何题型都写成配偶。

“用神”是本问所取的爻；生用者为元神、克用者为忌神，对这些生克链还要辨强弱与动静。财生官，对求官可能有助；财克父，对文章事项可能有碍。先列路径再判断，不能数几个“吉字”就下结论。

## 3. 判断顺序：有关系，不等于有作用

1. 写出用神为什么这样取；多个同类爻并见时说明选取理由，不暗中挑有利的一个。
2. 在有可靠历法字段时，比较月日的生扶、冲克与空破；日历日期不等于已排好的干支月日。
3. 分清静、明动和由日冲等条件讨论的暗动；《动静生克章》区分静旺爻的作用与动爻作用，不把所有静爻逐一连成无限生克网。
4. 看关键动爻变后对原爻的回生、回克、进退、合绊；区分本爻、变爻作用对象，不默认变卦所有爻都回克本卦所有爻。
5. 若所用不现，再在完整盘具备飞伏依据时讨论伏神。工具没有伏神不代表“用神绝无”，也不允许临时随造伏神。
6. 最后列主证、反证及其条件，落到本问的一条主判断。信息缺口造成的低把握应单列，不能既说必成又说必不成。

这是阅读次序，不是原书公布的分数公式。本轮不新增旺衰自动评分，不把古例结论写死成卦名映射。

## 4. 合、冲、空、破、反伏的条件

《六合章》分别讨论日月合、爻合、化合和六合卦，也区分静合起、动合绊。GE-001 岁考坎之困录佳绩，GE-002 诉讼泰卦却不利，不能据“六合”二字统一吉断。该章又有六冲变合可不看用神之论，与其他段落条件并不完全一致；保留分歧，不能冒称全书没有例外。

旬空以旬中缺支定义，不是文件里看到“空”就永久无效。《旬空章》既看气、动、受制，也用复占辅助；GE-003 同一求财事件两占仍无所得，而 RE-002 动空出空成婚。远近时限必须先定，不能事后任选年月日来贴合结果。

月破、冲、入墓、绝等同样要联系用神、时段与救应。“衰不必败、旺不必胜”不等于任意圆说；解释必须写明原始条件。反吟看反复往返，伏吟看停滞难舒，但仍察动变是否伤用；CA-003 反吟例有迁转不止，不宜一概凶。

## 5. 六神、卦名、卦辞不是独立裁判

《六神章》反对只凭青龙白虎断吉凶，称六神为附和之神。其类象可帮助描述，不可越过用神结构给现实人物贴“盗贼”“奸邪”等标签。缺六神字段时不写“临白虎”。

卦名、卦象说明总体意象，爻辞说明位置与关系。引用需书名、卦爻；引用“鼎玉铉”不能冒称金属物必定是玉环，射覆案例恰须结合残缺和形色。若原例依纳甲未引爻辞，就如实说未引；现代另引经文须标“补充义理”。

## 6. 应期与反例：先判事，再谈何时

先确定是否发生，再讨论时间依据。值、合、冲、出空、填破、出墓等候选往往不止一个；须写原先选择哪个、为何排除其他。只有年月日支而无年份的古例，不转为现实公历时间。

TR-003 明载“七月必到”却亥月到，应期未中必须保留；不能将后验解释“化出之爻”涂改为最初预测。CA-002 原断求差不得却三日内得差，后续解释不能抹掉初断失误。TR-002 先经历风雨阻船再悟取象，不是完整的事前预测。

古籍鼓励多占的观点可以研究，但插件不因此自动重起直到满意；同一事件复占要保留次序、原因与全部原断，并算同一事件，不当独立命中样本。

## 7. 当前插件能力与禁补字段

已具备：本/之卦、六爻值、动爻位置、卦辞爻辞、八宫与宫序、纳甲地支五行、六亲。尚未提供完整的日月干支/月建、旬空、伏神、六神及世应逐爻标注。古例中的这些字段是原书材料，不能迁移到用户当次排盘。

所以 AI 可以据已提供字段、经文和专题结构分析，明确缺项；不能说“本次世临月破”而工具没有这个结果。用户补充的历法也需核验来源与时区，公历生日不能擅自当起卦日期。

## 8. 参考与反馈形成可核对记录

回答建议：本问主判断 → 两三项主证 → 最强反证及取舍 → 范围/条件 → 一句断语。射覆先属性、后候选；天气先地点和时段及变化先后；健康不将古书生死辞用作医疗诊断、停药依据，金融和诉讼亦不替代现实专业判断。尊重文献不需要把其所有历史断言改写为当代事实。

原问题、原卦、AI 原断、后续反馈、揭晓答案分别保存；反馈发生后另作复盘，不能回写原断。命中应分属性命中、候选命中、时间误差，古书“果”与用户实际反馈不是同一等级。调用公开资料工具不查询私人群聊；查用户卦例仍走既有权限和隔离。
