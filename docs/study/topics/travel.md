# 出行与行人：能否动身、路途、归期分别看

研读：2026-09-24。体系：《增删卜易》纳甲；[基础](../foundations.md)；[版本](../sources.md)。

## 学习笔记

自己出行与代问他人返回，主体和取用不同；归期与在外安危也是两问。《行人章》明确区分，不能用“尚未回来”偷换成“遇险”。出行目的、行程距离和现实交通信息先保存，精确日期未提供就不造应期。

世动逢合可论受绊，但要说明阻碍依据；不是每次合都坏。行船占顺风与泛问天气亦不同，原书把子孙作行舟顺风解释，是“使行程解忧”的特定语境，不是固定气象风向公式。古例应期有误差与后验解释，应正面保留。

依据：[《出行章》](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy102.html)、[《舟行章》](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy103.html)、[《行人章》](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy105.html)、[《六合章》](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy21.html)。

## 古籍卦例

### TR-001 明夷之小过：世动合绊，未能出发

- 出处：《增删卜易·六合章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy21.html)；定位“申月 丙子日”“占出行”。
- 原问与时日：出行；申月丙子日。对话揭示其为筹女儿妆奁欲外出，女已患病。
- 卦象/关键爻：明夷之小过；世发动被子日合住，卯子动化辰官。具体病情是在交谈中得知，不是全由卦推得。
- 原断摘录：“合住必有事绊，不能动身。”
- 书载结果：因女病重未去；并记女死辰日。
- 整理者分析：区分“起行失败”与后续家庭事件；先验线索和用户补充背景分栏，不能假装未问背景即全知。
- 限制：古书疾病、生死叙述不可直接用于现代家人；本例无交通事故，不可误归为路途中险。

### TR-002 蛊之巽：风雨阻船，经历后才明确解释

- 出处：《增删卜易·行人章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy105.html)；定位“戌月 丙戌日”“由江右登舟”。
- 原问与时日：一路平安否；戌月丙戌日。
- 卦象/关键爻：蛊之巽；世酉官，五子父动化巳子孙。
- 原断摘录：“余疑酉金鬼爻持世，一路忧疑之象，初不知应风阻也。”
- 书载结果：戊子日风雨，泊南康后作者始以子父动解释；随后判断巳日晴。书称停舟五日，巳日晴而得顺风。
- 整理者分析：分三段保存：起初只知忧疑 → 遇风雨后的追认 → 此后对巳日的判断。不能把全部叙述压成一次事前精确预报。
- 限制：没有风速、航线、现代气象记录；“子孙为顺风”只在该行船语境，不等于全国气象规则。

### TR-003 屯之随：原断七月来，实际亥月到

- 出处：《增删卜易·行人章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy105.html)；定位“未月 戊戌日”“占伯何日来”。
- 原问与时日：伯何日来；未月戊戌日。
- 卦象/关键爻：屯之随；四申父动化亥兄，世寅子；原断父为用、克世速至。
- 原断摘录：“父母为用神，克世者速至，七月必到。”
- 书载结果：“后于亥月方到”，作者随后以父母化出之爻解释亥月。
- 整理者分析：到来这一方向与应期是两个评分项。应期未中应原样留存；不能把事后“亥月”改成 AI 的原断。
- 限制：年份与起终点未载，不能补公历到达日或路途原因。

## 给 Agent 的研判要求

先回答出发/到达/安全中的本问，说明主要阻力与必要条件；有可靠数据才讨论应期。天气可能影响行程时可调用天气专题，但不能用卦象替代预警和交通公告。复盘分别记录是否成行、延误及原因、实际到达时间；时间错了就明确记录错误。
