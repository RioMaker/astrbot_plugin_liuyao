# 感情：对象、意愿、成婚与后续分别判断

研读：2026-09-24。体系：《增删卜易·婚姻章》纳甲；[基础](../foundations.md)；[版本](../sources.md)。

## 学习笔记

原书婚姻例以传统男女财官角色为背景，并讨论世应与财官孰重。首先确定是谁问谁、问允婚还是相处、是否已有关系；现代关系不应因性别未知就擅填“妻”“夫”，更不能据一爻给对方贴外遇、欺诈或品行标签。

动态不等于立即实现；月破可问后续实破，旬空要看动静、生扶和时限。反吟描述反复，是否最终成仍需看支持与伤害的路径。原作者在同篇既有概括性忌语，也有例外，不可只抽最强硬的一句。

依据：[《增删卜易·婚姻章》](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy92.html)。本批三例都是作者记述婚成，未据此估计总体成功率；异例与战乱婚变等留待下一批对照。

## 古籍卦例

### RE-001 明夷之丰：眼下破，后年成

- 出处：《增删卜易·婚姻章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy92.html)；定位“子年 未月 己未日”“自占婚”。
- 原问与时日：自占婚；子年未月己未日。年号、公历未载。
- 卦象/关键爻：明夷之丰；四爻丑官持世动化午财回头生，原断同时指出月破、日破。
- 原断摘录：“目下虽破，终有不破之时。明岁丑年，定逢佳偶。”
- 书载结果：“果次年四月得配良姻。”
- 整理者分析：当前受阻和之后成婚是两个时段；要先说哪一时段，不能以“迟早会好”代替有范围的判断。
- 限制：没有现代恋爱过程记录；不能把应期年支直接推成用户婚期。

### RE-002 恒之鼎：财动生世，动空待出空

- 出处：《增删卜易·婚姻章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy92.html)；定位“子月 癸酉日”“恒之鼎”。
- 原问与时日：自占婚；子月癸酉日。
- 卦象/关键爻：恒之鼎；上爻戌财应发动化巳子，世为酉官；财生世而财值旬空。
- 原断摘录：“戌土虽值旬空，动不为空，明日出空之日，求之必允。”
- 书载结果：次日巳时允婚；书中并述夫妇白头、儿女成行。
- 整理者分析：“空”不能只当没有意愿，要同动与生扶一起看。允婚与长期相守应分项存，不把后者说成最初原断已详述。
- 限制：无人物姓名和独立婚籍记录；案例只提供传统论法，不证明现代关系的必然发展。

### RE-003 恒之晋：允而复悔，最终成婚

- 出处：《增删卜易·婚姻章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy92.html)；定位“巳月 戊子日”“占婚允否”。
- 原问与时日：婚事允否；巳月戊子日。对话中确认已有允后反悔，继问将来能否成。
- 卦象/关键爻：恒之晋；世酉官发动化卯兄，二亥父动化巳子，上戌财应动化巳子；原书论内卦反吟、财应动生世。
- 原断摘录：“内卦反吟，翻覆更变，允而复悔之象。”又断“八九月间必成”。
- 书载结果：“果于酉月成之。”
- 整理者分析：已知背景由当事人确认，不是全部独立预测。未来成否与已有反复不能混写；原断选择财生世作最终主证。
- 限制：不可把古例的“仍成”用于鼓励无视他人拒绝。现实同意与边界始终应尊重。

## 给 Agent 的研判要求

写清对象和问题层级，给一条主判断、支持路径、反证取舍及后续可核验条件；不以古书话术作人身指控。涉及婚礼钱款、迁居、家人意见，可跨查财富、家庭、出行，但不自动认定每个主题都需要另起一卦。
