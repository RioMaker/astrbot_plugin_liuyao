# 家庭与家宅：谁的事、哪一处、哪一阶段

研读：2026-09-24。体系：《增删卜易》纳甲；[基础](../foundations.md)；[版本](../sources.md)。

## 学习笔记

家庭类先区分家人情况、房屋交易、入住安排与相处。取父母为宅舍不等于问父母本人；同一“父母”符号可因原问有不同所指。原书家宅章强调分别问具体家人，也在旧宅章反对用一卦硬指大宅中所有灶门和全家祸福。

下列入宅例是传统择时与趋避叙事，可学其区分对象与列证，不能据“迁床后平安”认定现代医学或建筑因果。住房交易要看实际产权、结构和居住条件；古例凶亡不等于宅必有害。家庭反馈也不宜把每个成员隐私自动补全。

依据：[《入宅六亲吉凶章》](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy122.html)、[《旧宅章》](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy124.html)、[《盖造买宅赁宅章》](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy117.html)。不采用网页“乾按”的现代气场解释。

## 古籍卦例

### FA-001 萃卦：同日入宅，不同家人分别论

- 出处：《增删卜易·入宅六亲吉凶章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy122.html)；定位“子月 丁酉日”“有碍父母否”。
- 原问与时日：选某日入宅，有碍父母否；子月丁酉日。
- 卦象/关键爻：泽地萃，原例静卦；卯财受日冲，原断以暗动克未父论。
- 原断摘录：“父母于申时入宅，汝于寅卯时入宅。”
- 书载结果：作者称依此安排，亲见平安十七载；另有安床西南的叙述。
- 整理者分析：回答的是具体父母与时间，不是一个“合家大吉”标签；当事人与父母不能混用同一个位置。
- 限制：未载十七年逐年记录或对照，不能证明入宅时刻导致平安；不转为强制搬床、改日或医学建议。

### FA-002 革之丰：子女入宅，忌动还有强弱进退

- 出处：《增删卜易·入宅六亲吉凶章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy122.html)；定位“卯月 丁卯日”“子女安否”。
- 原问与时日：某日入宅对子女安否；卯月丁卯日。
- 卦象/关键爻：革之丰；五酉父动化申父为退，初卯子临日月。
- 原断摘录：“父动克子，幸子孙临日月，父母又化退神。”
- 书载结果：按建议亥子日迁居、南房安床；后记长子卯岁登科。
- 整理者分析：有克不等于只剩克，原断同时列子旺和父退。结果记录的登科属于延伸后事，不能替换原问“入宅安否”的全部细节。
- 限制：无具体科名、年号和子女健康记录；不推导“住南房必考中”的因果公式。

### FA-003 革之夬：宅可买与家人风险分开

- 出处：《增删卜易·入宅六亲吉凶章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy122.html)；定位“申月 辛卯日”“占买此宅吉否”。
- 原问与时日：买宅吉否；申月辛卯日。
- 卦象/关键爻：革之夬；世亥兄得月生、日冲酉父生世；二丑官动化寅子，原书据化出子孙受月冲提出另一个风险。
- 原断摘录：“此非宅之故也，即使不买此宅，亦恐难保。”
- 书载结果：当事人先弃买，子八月死于痘，十月仍买此宅。
- 整理者分析：原作者自己明确否认“买宅造成此事”。记录时不能倒写成房屋有灾；也不能称买后兴旺已实证，因为正文未继续记买后收益。
- 限制：历史病亡不作用户未来死亡预判；“不买仍发生”也不能证明断法的普遍效力。

## 给 Agent 的研判要求

锁定具体家人或住房事项，解释取用，给有范围的判断及现实可核验点。不从卦象猜成员病史、指责亲人或主张房屋必致灾。钱款查财富，亲人归期查出行，实际健康问题查健康边界；跨读不自动扩写全家命运。
