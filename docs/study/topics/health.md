# 健康：研读传统病占，严格区分对象与时段

研读：2026-09-24。体系：《增删卜易》纳甲病占；[基础](../foundations.md)；[版本](../sources.md)。

## 学习笔记

原书区分自占以世、代亲人按亲属取用，也分近病与久病。官鬼在某些自占病语境为病忧，在占父母时可能为元神、在妻占夫时可能直接为用；故“见官皆病”“见子皆救”都不成立。原文野鹤与觉子关于代占解忧的解释有补充和异议，须标明立场。

近病短暂恢复与多年后另一疾病是两件结果，不得以日后的结局抹掉当时恢复。病例叙事不具现代诊断、病历和对照条件，不能拿古文死亡判断作医学预测、药物选择或延误就医依据。这里的学习目标是取用与证据组织，不是临床规则。

依据：[《增删卜易·疾病章》](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy110.html)。其“三合六合使近病成久病”等强断只保留为古说，不当作医学因果事实。

## 古籍卦例

### HE-001 恒之解：子近病，近愈与远事分记

- 出处：《增删卜易·疾病章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy110.html)；定位“申月 庚寅日”“占子近病”。
- 原问与时日：子近病；申月庚寅日，后文说明辰年占。
- 卦象/关键爻：恒之解；三酉官世动化午子，午子临旬空；原作者并论“鬼变子孙”与近病空的不同层面。
- 原断摘录：“幸子孙临旬空，近病即愈，恐其难过午年。”
- 书载结果：出空日愈；至午年书称因痘症死亡。
- 整理者分析：应保存“当时恢复”和“后来另一疾病”两个时段，不把它们合成正反任选的单一结局。古文预测与后来叙述均有记录，但不等于现代疾病因果。
- 限制：无病历、病原或治疗资料；不能把“痘症”按现代分类确诊，不能迁移死亡年份到用户。

### HE-002 遁卦：代占子病，世上鬼解释为问者之忧

- 出处：《增删卜易·疾病章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy110.html)；定位“申月 壬子日”“占子病”。
- 原问与时日：占子病；申月壬子日。
- 卦象/关键爻：天山遁，原例静卦；世午官受子日冲。
- 原断摘录：“官鬼持世，尔之忧也，今日子日，冲去忧心，管许立愈。”
- 书载结果：“果愈于本日。”
- 整理者分析：作者在代占语境用“忧”释世鬼，不能挪成患者必有某病。紧接的觉子评论指出占父母或妻占夫，官可为元神/用神，不宜再照搬子孙克官解忧。
- 限制：原书没有清楚病名和恢复判据；不得因此让现实患者停止治疗。

### HE-003 屯之节：妻病，子孙化进与原书的取用异议

- 出处：《增删卜易·疾病章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy110.html)；定位“寅月 乙卯日”“占妻病”。
- 原问与时日：妻病；寅月乙卯日。
- 卦象/关键爻：屯之节；二寅子持世动化卯子，妻财未在本卦明现。原断用“喜悦”解释。
- 原断摘录：“未日即愈。”
- 书载结果：“果午日退灾，未日大愈。”
- 整理者分析：区分初步减轻和明显恢复两个反馈点。原作者用木墓于未释应期，而不是通用“越旺越快”；后注再提醒子孙不是对所有亲属皆为喜悦。
- 限制：这种解释依赖完整日月与取用，不能只看到子孙动就断现代疾病痊愈；未载具体治疗。

## 给 Agent 的研判要求

可以明确描述传统取象倾向和缺项，但不诊断疾病、不预测死亡、不指导停药或替代就医。用户问实际症状应优先现实医疗帮助。健康断语应围绕可行动的观察、支持和就医安排，不给确定痊愈日期；群内反馈只存用户明确提供的内容，不补敏感病史。
