# 学业：文书、科名与实际备考条件

研读：2026-09-24。体系：《增删卜易》纳甲；[基础](../foundations.md)；[版本](../sources.md)。

## 学习笔记

先区分学习进度、资格材料、考试、录用。古代乡会试主要讲官、父、世如何相互作用；不能把“官旺”当现代所有考试必过，也不能由“兄弟”一字断竞争必败。原书有财局生官、六冲而中等例外，必须把作用路径说出来。

文书与科名可不在同一层：材料合格不保证录取，成绩好不等于职位到手。现实复习、报名资格、考试日期以用户提供为准；卦象不能编出学科薄弱点或精确分数。考编等跨事业，证件手续跨出行时允许查询其他专题。

依据：[《增删卜易·乡试会试章》](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy62.html)。下列选三种不同结构，不把同一人复占算两例。

## 古籍卦例

### ST-001 艮之益：财局生官，不机械断子动克官

- 出处：《增删卜易·乡试会试章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy62.html)；定位“卯月 甲申日”“占会试”。
- 原问与时日：会试；卯月甲申日。
- 卦象/关键爻：艮之益；五子财、三申子、初辰兄发动。世寅官得月，原断以申日冲世暗动、日辰会成财局生世论。
- 原断摘录：“不惟不克世爻，反来生世，一定高捷。”
- 书载结果：“果得及第。”
- 整理者分析：同有子孙动，不必只取克官这一个关系；原书在这里用会局改变作用方向。要明确局成立所需字段，不能用同类字数凑局。
- 限制：未载榜次、成绩或年份，不能换算用户考试排名。

### ST-002 兑，再临之师：六冲不能单独否决

- 出处：《增删卜易·乡试会试章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy62.html)；定位“午月 丙辰日”“占乡试”。
- 原问与时日：乡试；午月丙辰日。同一事件先兑卦，继临之师。
- 卦象/关键爻：兑为六冲，未父持世得旺；再卦初巳父动化寅官，卯官持世。
- 原断摘录：“此卦官星持世，虽则不旺，而初爻官生文旺，与前卦相合，许之必发。”
- 书载结果：“果得中式。”
- 整理者分析：第一卦因六冲与父世旺相有分歧，原作者未立即下断，随后以复占相互参照。这段不应裁成“见兑即高中”。
- 限制：复占属原书方法记录，AI 不自动连续重起以求吉；无动爻的第一卦不可臆造变卦。

### ST-003 离之既济：化官还要看是否回头克

- 出处：《增删卜易·乡试会试章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy62.html)；定位“卯月 戊辰日”“离之既济”。
- 原问与时日：乡试；卯月戊辰日。
- 卦象/关键爻：离之既济；上巳兄世动化子官回克，五未子及四酉财亦动。
- 原断摘录：“因变出子水之鬼，回头克世故耳。”
- 书载结果：“后客死于途中。”未另载本次考试成绩。
- 整理者分析：觉子借此反对“身官化鬼月扶便连捷”的概括。关键是变后关系，不是见官字就认作录取。
- 限制：死亡是古书所述，不以此替现代考生作生死预测。未有成绩就不补“落榜多少名”；只记书载旅途结局与作者论点。
