# 财富：求财、借贷、放贷与长短时段

研读：2026-09-24。体系：《增删卜易》纳甲；[基础](../foundations.md)；[版本](../sources.md)。

## 学习笔记

先问收入、应收到账、借款能否获准、经营收益还是资金损失，不把所有钱事混成“财运”。古书以财为核心、子孙为财源，兄弟与官鬼的作用随生克链变化：兄动可劫财，也可能有子孙承接；官可制兄，又可能泄财。必须说明本例是哪条链，不套固定吉凶。

尤其要区分近期一笔款与长期可持续收入。短期到款不等于长期投资成功，借到钱不等于取得利润。例中未有金额、成本、利率就留空；不根据五行数编造收益和价格目标。

依据：[《增删卜易·求财章》](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy77.html)。以下选“放印子钱”“借贷”“目下求财”三种不同原问，保留书中对概括口诀的反驳。

## 古籍卦例

### WE-001 未济之归妹：放印子钱，兄多不等于不劫财

- 出处：《增删卜易·求财章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy77.html)；定位“巳月 丙辰日”“占放印子钱”。
- 原问与时日：放印子钱；巳月丙辰日。
- 卦象/关键爻：未济之归妹；上巳兄动化戌子，初寅父动化巳兄，世为午兄。原文以月建、世、动变多兄论。
- 原断摘录：“占时顺遂，至九月，兄爻入墓，因奸破耗。”
- 书载结果：此句位于“断曰”段，叙述顺遂后破耗，未另单列“果……”验辞；因此标为原断与叙述未分明，不当独立已验样本。
- 整理者分析：本例被作者用来反对“兄多反不劫财”。先保存风险理由与期限，不能由一句口诀把多重耗损当作自动抵消。
- 限制：不知本金、利息及事后账目。“印子钱”属历史借贷语境，不转成现代放贷建议。

### WE-002 晋卦：兄弟持世而借贷得款

- 出处：《增删卜易·求财章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy77.html)；定位“未月 丁卯日”“占借贷”。
- 原问与时日：借贷；未月丁卯日。
- 卦象/关键爻：火地晋，未列明动变卦；世酉兄受卯日财冲，应未父旺而生世，原断随后以世动逢合取辰日。
- 原断摘录：“兄爻持世，固曰无财，但喜卯日，即是财星。”
- 书载结果：“果得于辰日。”
- 整理者分析：明动与日冲所论暗动要分清；不能因静卦就否定原作者所说的日冲作用。借得一笔款是本题结果，不是收益增长。
- 限制：未载还款与资金成本；缺日干支的用户盘不能使用此例的日冲、辰日应期。

### WE-003 既济之涣：眼前到账，不代表长久有财

- 出处：《增删卜易·求财章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy77.html)；定位“巳月 丁巳日”“占求财”。
- 原问与时日：求财；巳月丁巳日。
- 卦象/关键爻：既济之涣；三亥兄世动化午财，上子兄应动化卯子；初、二也动。原断以世日月破、不克变财，财冲世，应空待冲实论。
- 原断摘录：“若占久远之财，则无财也。若问目下之财，明日戊午必得。”
- 书载结果：“果于次日送来。”
- 整理者分析：只有次日到账被书中记载，不能将“久远无财”标作另一个已验结果。先限定时段才能避免正反两说。
- 限制：款项性质、金额、后续经营未载；未由此提供证券买卖或收益保证。

## 给 Agent 的研判要求

先答“这笔钱能否取得/能否按期到账”等具体问题，列主要来路、阻碍和时间条件，最后断语。对投资、借贷应结合现实资金风险，不给卦象保证收益；必要时跨读事业或家庭。后续反馈应分别记到账时间、数额（用户明确提供才记）与经营结果，不互相替代。
