# 综合与辨证：先限定问题，不以一个标签包断全局

研读：2026-09-24。体系：以《增删卜易》纳甲为主。三例是独立事件，均属古籍记载；不是本插件的用户反馈。[基础](../foundations.md)；[来源版本](../sources.md)。

## 学习笔记

综合问题先拆成明确的对象、时段和目标，再查对应专题。问“最近怎么样”时先明确最关心的事，而不是一次断事业、疾病、婚姻全有结果。取用随所问变化；世、用、应并非三个永远固定的人。

合局、六冲、旬空属于有条件的结构，不能当独立成败按钮。六合章一面强调用神有气，一面存在六冲变合的特别说法；旬空章又主张复占互参。整理时保留原文差异，不为了制造统一口诀消除分歧。实务中先写规则适用条件，再用案例做比较；同卦名但问题不同不能直接复制答案。

主要依据：[《增删卜易·六合章》](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy21.html)、[《旬空章》](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy30.html)。

## 古籍卦例

### GE-001 岁考：坎之困，六冲变合而获佳绩

- 出处：《增删卜易·六合章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy21.html)；定位“丑月 戊申日”“占岁考”。
- 原问与时日：岁考；丑月戊申日，年份未载。
- 卦象/关键爻：坎之困。原断举世爻子水与丑月合、申日父母生世、卦中申金发动，六冲变六合。
- 原断摘录：“卦称全美，上誉无疑。”
- 书载结果：“果考一等，即于子科高发。”另追述此前考过四等。
- 整理者分析：不是仅因变六合就吉，原断同时列合世、生世、父动。记录前后阶段可表达由困顿向改善，不把先前四等误当本次结果。
- 限制：科举等级不能换算现代分数；“子科”不补公历年份。书载没有现代独立考试凭证。

### GE-002 讼事：泰卦，六合不抵世受伤

- 出处：《增删卜易·六合章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy21.html)；定位“戌月 丁卯日”“占讼事”。
- 原问与时日：讼事；戌月丁卯日。
- 卦象/关键爻：地天泰，原例没有明动变卦。原断论戌月冲世、卯日克世，应爻暗动又得月生。
- 原断摘录：“彼之得志，官事必输。”
- 书载结果：“已而被杖。”
- 整理者分析：比较 GE-001：同谈合，世用条件与问事不同，结论不同。此例适合学习主证压过表面吉象，而非给“泰”贴永吉标签。
- 限制：古代诉讼与刑罚只作历史记录；不能用来判断当代法律责任、定罪或诉讼胜率。没有载明结果日期。

### GE-003 求财：家人之贲，再睽之损，空与受制合看

- 出处：《增删卜易·旬空章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy30.html)；定位“辰月 乙卯日”“占求财”。
- 原问与时日：求财；辰月乙卯日。同一事件先家人之贲，再睽之损，合计一例。
- 卦象/关键爻：初卦丑财持世旬空，巳火元神又化回头克；再卦子财空伏于未土下且受克。此处伏神来自原书，不是当前插件自动排出。
- 原断摘录：“财无气矣，不必劳心。”
- 书载结果：“后果毫厘未获。”
- 整理者分析：原作者先因“财空而尚有气”迟疑，复占后作判断；不能抹掉迟疑，伪装一眼断定。例证说明须关注生扶是否真正能作用。
- 限制：这是古书多占方法，不授权 AI 为用户反复自动起卦。未载求财金额、具体交易和结果日期；不能据此训练金额预测。

## 给 Agent 的研判要求

先给本问主判断，写清主证与最强反证怎样取舍。若类别不明确，询问或按语境选择，并可再调用任意专题。通则不替代分类：天气不用成败模板，射覆要属性，医疗与法律不得凭卦断事实。缺历法和世应等字段时不补造；查询古籍案例不等于已查询本群历史。
