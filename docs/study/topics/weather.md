# 天气：分地点、分时段、分晴雨过程

研读：2026-09-24。纳甲主线以《增删卜易·天时章》为准；[基础](../foundations.md)；[版本](../sources.md)。简版自动参考另见 [天气简版](../../../data/references/weather.md)，此篇补学习笔记与三例。

## 学习笔记

原书要求明确所问地点：城或乡、本处还是远方；没有地点就无法把“有雨”当可检验判断。先确认晴雨问题、日期/时段、已知天气；缺项先问，不从群所在地猜用户所在地。

该篇以子孙为日月星斗、父母为云雨雪霜；财动可克父使晴，却不一定无云；兄主风云，官常为浓云雷电的层次。动变要落到过程：先阴后晴、先雷后雨等，不把整天写成“晴雨都有”。原书说官动不必每次响雷，WX-001 亦说明远方雨不等于本地大雨。

文献分歧必须保留：《火珠林·占天道晴雨》有子孙云雾/冬雪说；《增删卜易》用雪后转晴反驳。后者还反对只因父旺即断连旬雨，天时强调实际时势与动变，不能把人事旺衰口诀完整搬来。

主要依据：[《增删卜易·天时章》](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy42.html)、[《火珠林·占天道晴雨》](https://zh.wikisource.org/wiki/火珠林)。这些是古代占候理论，不是现代气象观测。出行顺风另查出行，不能混成实际风向风速预报。

## 古籍卦例

### WX-001 恒之大过：远方雷雨，本处只有数点

- 出处：《增删卜易·天时章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy42.html)；定位“巳月 丁卯日”“占何日雨”。
- 原问与时日：何日雨；巳月丁卯日。具体地名未载。
- 卦象/关键爻：恒之大过；五申官明动化酉官进神，世酉官受日冲论暗动；亥父本例不动。
- 原断摘录：“世爻酉鬼暗动，申鬼明动化进神。”
- 书载结果/叙述：“本日申时，霹雳惊人，远方大雨，本处洒来数点耳。”此段将判断与天气叙述合写，未另分验辞。
- 整理者分析：即使雷电明显，也必须区分远近和当地雨量层级。不能把“远方大雨”记为“本地大雨”的命中。
- 限制：无站点、毫米数与观测记录；不标精确降水概率。原作者反驳把少雨只归因于父月破，不能省掉这层异议。

### WX-002 困之比：连雨问晴，雨象与晴象按先后分开

- 出处：《增删卜易·天时章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy42.html)；定位“辰月 丙辰日”“因连雨，占本日晴否”。
- 原问与时日：连雨后本日晴否；辰月丙辰日。
- 卦象/关键爻：困之比；二辰父动化巳官回生，四亥子动化申兄回生。父与子同时有动变，不据此只断彩虹闪电。
- 原断摘录：“断申时天开，亥时睛霁。”
- 书载结果：“果于亥时万里无云。”
- 整理者分析：明确主要转晴结论，并说明变化先后；亥为夜间，“晴”可指云散见星，不能改写成亥时太阳出来。
- 限制：书载只明确亥时无云，没有独立再证申时那一阶段；未载地名，不能套用到用户城市。

### WX-003 观之比：雪后问晴，子水不直接等于雪

- 出处：《增删卜易·天时章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy42.html)；定位“子月 己亥日”“因连日雪”。
- 原问与时日：连日雪后何日晴；子月己亥日。
- 卦象/关键爻：观之比；上卯财动化子水子孙，原断还论两火鬼暗动而本日仍阴。
- 原断摘录：“卯财化出子水子孙，明日卯时必晴。”
- 书载结果：“果于次日卯时，云开日出。”
- 整理者分析：原书拿此例反对“冬令子孙为霜雪”；既记录该书的主张，也保留其他文献异说，不能拼合成冬季既必雪又必晴的规则。
- 限制：没有积雪深度、温度、融雪速度；“转晴”不等于当天冰雪道路安全。

## 给 Agent 的研判要求

输出：地点与时段 → 晴雨主判断 → 风云雷电及变化先后 → 卦象主证/反证 → 一句限定时空的断语。无日月干支、旬空等字段，不能照古例补具体时辰。不要编毫米、温度或概率；涉及灾害与行程安全，实际安排应查可靠气象预报和预警。

反馈记录原定地点时段及用户实况，分辨降雨、雷电、云量和时间误差。夜间无云与日照不同，周边降雨与本处不同。保留原预测，不用反馈重写原断；古例不当本群实测卦例导入。
