# 事业：求职、升迁、候补与到任分开

研读：2026-09-24。体系：《增删卜易》纳甲。三个古例涵盖未得、初断错误、迁转；[基础](../foundations.md)；[版本](../sources.md)。

## 学习笔记

先区分“职位是否归我”“何时获任”“何处任职”“任后处境”。古代功名章节以官、世、财禄等看不同层面；现代求职可作结构类比，不能把古官职制度直接套进所有劳动合同、项目经营。薪资另查财富，考试录用交叉查学业，异地到岗再查出行。

官局旺不等于一定属于问卦人，要看生世还是生应。官化进、回生与反吟不能离开用神状态。对于原作者失误的例子，明确写“先断错，后解释”；不能训练模型用事后悲剧抵消原问题判断错误。

依据：[《升选候补章》](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy63.html)、[《反伏章》](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy29.html)。前者正文也否定仅用“晋升吉、屯蹇凶”定事。

## 古籍卦例

### CA-001 占缺：井之节，官局生应而他人获任

- 出处：《增删卜易·升选候补章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy63.html)；定位“申月 乙亥日”“占缺得否”。
- 原问与时日：能否得到此缺；申月乙亥日。
- 卦象/关键爻：井之节。初丑土财动化巳火子孙，三酉官动化丑财；原断以内卦巳酉丑官局生应而不生世论。
- 原断摘录：“此缺不得。”
- 书载结果：“后果另选他人。”
- 整理者分析：先判断资源与职位归属；不能把“官局成立”直接等于“我获任”。该例明确区分机会存在与机会属于谁。
- 限制：未载竞争人姓名、筛选条件与应期，不能补“有人暗箱操作”。

### CA-002 求差：夬卦，保留“不得”这一原断失误

- 出处：《增删卜易·升选候补章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy63.html)；定位“申月 戊寅日”“占得差否”。
- 原问与时日：能否得差；申月戊寅日。
- 卦象/关键爻：泽天夬，原例静卦；世爻酉金子孙临旬空。
- 原断摘录：“子孙持世，此差不得；世空，亦不能得。”
- 书载结果：“岂知不出三日得差，行至中途而死。”
- 整理者分析：对“得差否”的初断与结果相反。作者事后以三日内尚未出空解释得差，再以世空解释中途身亡；这些是后验说明，不能覆盖原断。
- 限制：后事不证明最初对职位的判断正确。不得按同卦给现代用户断死亡，更不能用“凶事应了”把错误记为成功。后文其他人求缺不是这一次复占。

### CA-003 升迁：临之中孚，迁往他处又复任原地

- 出处：《增删卜易·反伏章》；[原文](https://www.quanxue.cn/qt_mingxiang/zengshanpy/zengshanpy29.html)；定位“卯月 己亥日”“占升迁”。
- 原问与时日：升迁；卯月己亥日。
- 卦象/关键爻：临之中孚；原断世临卯木官星，得月令与亥日生，外卦反吟。
- 原断摘录：“世与官星同临旺地，许之即升。”
- 书载结果：本月由江西升山东，不及一年又任江西；原书分别以官旺和外卦反吟解释升迁及往返。
- 整理者分析：反复变化不必等于失败；把“是否升”和“任地是否稳定”分栏，主次才清楚。
- 限制：转回原地的解释出现在结果叙述后，不夸称最初已逐项预报全部履历。地点不能由卯木机械映射为现代某省。

## 给 Agent 的研判要求

输出职位/项目归属的主判断、关键助阻、阶段与条件、一句断语。不得把所有风险平铺成“可能好也可能坏”；也不得凭未提供的官世、月日字段假装算过。可任意调用财富、学业、出行文档，注明哪个是主问题；保留原断供后续反馈核验。
