# 射覆：先属性，后候选；不同取象体系分开

研读：2026-09-24。[基础](../foundations.md)；[版本与异文](../sources.md)。三例均来自古书，有明确本卦、之卦；不是现代网友补出的排盘。其中两例属梅花取象，不能标为纳甲实证。

## 学习笔记

《火珠林·占射覆》有“以财为体，以鬼为类”，又分财表鬼里，并用世应论形制；“覆射物色”还列官色、五行、伏藏等。它和《梅花易数》用体用、互卦、变爻、爻辞的框架不同。同一本《火珠林》的表里说法也有不同层次，需注明所取段落，不能混为无条件算法。

依据：[《火珠林·占射覆、覆射物色》](https://zh.wikisource.org/wiki/火珠林)、[《梅花易数》卷三“观物用易例”等](https://zh.wikisource.org/wiki/梅花易數/卷三)。只读传统规则，不把同卦等于同物，更不因先看见答案而重新挑颜色或材质。

现代输出格式（整理者约定，非古籍原句）：

1. 颜色/光泽；材料；软硬与柔韧；形状/大小/完整程度；用途；关联场景。每项给依据，弱项写“不足以定”，不可所有属性都填高确定度。
2. 总结两三条最强属性，排除明显冲突者，给 2～4 个可能物品并排序，明确首选。物品名称应由属性收敛，不先猜名字再倒填。
3. 引用案例时说相似点及差异；若借梅花类象，明确是辅助取象，不用它伪造当次互卦、体用。
4. 揭晓后保留原属性、原候选与顺位、实际答案、差异，不以新答案覆盖原断。古例与群内射覆答案分库。

## 古籍卦例

### SF-001 姤之履：金、玉、琥珀三指环

- 出处：梁萧绎《金楼子》卷六·自序篇十四；[原文](https://zh.wikisource.org/wiki/金樓子/卷六)；定位“余將冠，方好《易》卜”“從兄平西令吾射”。
- 原问与时日：射所藏物；仅记赴郢州情境，年月日未载。
- 卦象/关键爻：姤之履。叙述有寅爻取虎/琥珀的关联；完整六爻、纳甲、世应与起卦数值未载，不补造。
- 原断摘录：“上旣爲天，其體則圓。”“合中之物，凡有三種。”
- 书载结果：自述所射为金、玉、琥珀三指环，文字将这些材料与取象对应；没有单独的开覆过程和独立验者记录。
- 整理者分析：可见圆形、不同材质、轻重差异、三件的层次。硬度、尺寸及现代“饰品用途”是对物品的常识整理，不是原断逐项提供，不伪称古文说出全部属性。
- 限制：同段“寅爻帶乎虎”有后世校勘异文，未据刻本解决。原书自称命中比例不能作为插件准确率。三只环是同一事件，只计一例。

### SF-002 泰初变升：连根草木

- 出处：《梅花易数》卷三·观物用易例；[原文](https://zh.wikisource.org/wiki/梅花易數/卷三)；定位“有人以籠盛物者”。
- 原问与时日：笼中所盛为何物；时日未载。
- 卦象/关键爻：地天泰初爻变升，原文互见震、兑；属于梅花取象，不配纳甲用神。
- 原断摘录：“色青根黃，當連根之草木也。”所引爻辞：“拔茅茹，以其彙。”
- 书载结果：“視之乃草木連根，新采於土中也。”
- 整理者分析：从植物类别、青色、黄根、连根且新采几个属性收敛；能参考“结构关系比颜色单点更有辨识度”。原例用兑解释黄根，不能擅改成另一套固定兑白规则再声称是原法。
- 限制：植物具体种属、用途、长度与软硬未载；不补作某种蔬菜。笼是容器，不是最终答案。

### SF-003 鼎之恒：破玉绦环

- 出处：《梅花易数》卷三·观物用易例；[原文](https://zh.wikisource.org/wiki/梅花易數/卷三)；定位“又有以鍾覆物者”。
- 原问与时日：覆物为何；时日未载。
- 卦象/关键爻：火风鼎之雷风恒；原文互见乾、兑，引用“鼎玉鉉，大吉”。原文没有逐项纳甲六亲，不能补称财鬼用神例。
- 原断摘录：“雖圓而今毀缺矣。其色白而可用。”
- 书载结果：“開視之，乃玉絛環，果破矣。”
- 整理者分析：白、圆、已破、有用及贵重联想共同缩小候选；形状与残缺强于泛泛说“金玉”。用途可以写环佩关联，但其具体佩戴方式原例未展开。
- 限制：硬度、大小未载。原文是鼎，不采“火风升”讹字；不可把“钟”这一覆盖器认作被猜物。

## 给 Agent 的研判要求

当前是六爻起卦，应以已返回的卦、动爻、六亲为主。可跨查基础及任一主题，但不能把问者职业或上下文猜测冒充卦象必然属性。最终给首选和少量备选，不无限列举。反馈应分别核对颜色、材料、软硬、用途和候选顺位；没说到的属性不算命中。
