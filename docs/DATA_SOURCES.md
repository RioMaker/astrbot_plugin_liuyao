本文件先固定候选来源、许可与字段边界，再逐步扩充解释层，避免把不明来源的现代“解签文”混入古籍原文。

## 六亲与纳甲规则

najia.py 的运行时规则来自以下公版古籍表述，不需要联网：

- [《增删卜易·六亲歌章第五》](https://zh.wikisource.org/zh-hans/增删卜易/5)：确定“生我父母、我生子孙、克我官鬼、我克妻财、比和兄弟”，并明确六亲以本卦所属卦宫五行为“我”；变卦六亲仍沿用本卦卦宫五行。
- [《卜筮正宗》](https://ctext.org/wiki.pl?chapter=889452&if=gb)：校核八宫所属与纳甲装卦表，包括乾子寅辰/午申戌、坤未巳卯/丑亥酉等内外卦地支次序。

实现按初爻到上爻保存地支，先由八宫序列判定本卦卦宫，再以每爻纳甲地支所属五行计算六亲。测试覆盖 64 个阴阳组合，保证八宫各八卦唯一归属，并用《增删卜易》“乾为天”示例逐爻校验。

## 意图签词结构

`data/intents.json` 已预留：

```json
{
  "hexagram": 1,
  "intent": "career",
  "source": "《周易·乾·九五》",
  "quote": "飛龍在天，利見大人。",
  "guidance": "现代方向提示"
}
```

扩充规则：

1. `quote` 只放可核验的古籍原文，`source` 精确到卦与爻。
2. `guidance` 是现代整理，必须与原文分栏，不能伪装成古籍。
3. 同一卦可覆盖多个方向，但不得为了凑齐分类强行改写吉凶。
4. 医疗、法律、投资方向只能给反思问题和风险提示，不给确定性结论。
5. 每批新增数据都要补充来源 revision/底本并加回归测试。
