## 天气原文摘录候选与取舍

摘录均为以上转录文本的古籍句子，以下说明为现代整理。

| 定位 | 原文短摘 | 首版处理 |
| --- | --- | --- |
| W2《天时》篇首 | 当究父财，勿凭水火。 | 采用六亲主线，禁止以卦名水火直接判天气 |
| W1“子孙为日月星斗”段 | 子孙发动，万里无云 | 与同段财动而子弱可有云的说明同看，不作为无条件保证 |
| W1“父母为雨雹雪霜”段 | 或城或乡，指其地而占之。 | 地点与观察窗口必须明确 |
| W1“父化兄”段 | 若以次序，则动先而变后。 | 转为真实动爻的候选先后链，不把静爻当动 |
| W1“母化子”段 | 母化子，雨后晴明；弟化孙，云开日出。 | 不机械添加彩虹 |
| W1“父持月建”段 | 余试天时，旺衰不论。 | 保留与W2的分歧；不声称所有六爻都不看旺衰 |
| W1“官鬼雷霆雾电”段 | 或为黑云，或应雷电 | 不把鬼动唯一对应雷暴 |

W1 中“大壮之夬”“困之比”“明夷之艮”等为作者自述验例，可供后续人工整理，但本版未导入群内实证卦例库，也未当作准确率样本。部分排盘日期带问号、表格缺分隔，不能无校勘导入结构化案例。
